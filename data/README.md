# Данные проекта

Файл `telco_clean.csv` создан при успешном запуске ноутбука в Google Colab, но его не было среди загруженных сюда файлов.

Чтобы добавить его в GitHub, скачайте `data/telco_clean.csv` из панели «Файлы» в Colab и поместите сюда.

Ноутбук сам загружает исходные данные из IBM GitHub и создаёт `data/telco_clean.csv`, поэтому при наличии интернета он запускается без заранее сохранённого CSV.
